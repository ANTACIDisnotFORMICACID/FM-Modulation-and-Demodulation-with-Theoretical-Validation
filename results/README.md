# Experiment results

This directory contains outputs generated by the experiments in `scripts/`. Regenerate them from the scripts instead of editing the output files by hand. Run `python scripts/run_all.py` for the original `exp01`–`exp05` experiments and `python scripts/run_sdr_experiments.py` for the complex-baseband E1–E7 experiments.

- `figures/` contains PNG and PDF plots for `exp01`–`exp05`, plus a PNG diagnostic plot for reception of the real IQ recording.
- `data/` contains numerical results in CSV and JSON files named after their experiments.
- `sdr/` contains E1–E7 CSV files, configuration, PNG plots, and reports from the software transceiver and real-IQ receiver. Derived WAV files are kept locally. Reproducing the real-IQ receiver output requires the recording described in [`data/real/README.md`](../data/real/README.md).

The corresponding experiment scripts define the parameters, sample rates, and random seeds. Complex-baseband experiments also save `sdr/experiment_config.json`. CSV filenames and column headers alone do not specify the full experiment configuration.
